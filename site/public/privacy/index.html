Privacy for your photo folders

Effective August 28, 2026.

The CLI stays local

The CLI has no telemetry and makes no network requests. It reads folder entries and recipe files on your device.

It writes only the recipe file or checklist path you request. It never writes to photos or editor sidecars.

The website keeps files in memory

The recipe file checker reads your selected file in this browser tab. It does not upload or save that file.

The site has no analytics, ads, cookies, accounts, or third-party scripts. The service worker caches only public site files for offline use.
