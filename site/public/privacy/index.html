Folder Recipe

Privacy, kept local.

Effective August 27, 2026.

The CLI

Folder Recipe has no telemetry and makes no network requests. It reads folder entries and recipe manifests on your device. It writes only the manifest or checklist path you explicitly request.

The website

The manifest inspector parses the file in your browser. It does not upload, transmit, or persist the file. The site does not use analytics, advertising, cookies, accounts, or third-party scripts.

Questions

Open an issue in the public repository for privacy questions.
