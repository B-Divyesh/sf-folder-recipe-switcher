02 Archive rhythm

Decide once. Verify in context.

Each folder can set its own rule or inherit the nearest parent. You can see which one applies before opening an editor.

  1. 01

    Record

    Map editor names to exact profiles and note why this shoot differs.

    folder-recipe init ./shoot …
  2. 02

    Inspect

    See direct versus inherited intent alongside extensions, count and size.

    folder-recipe inspect ./shoot/selects
  3. 03

    Carry

    Export a checked list for a mixed archive before the first import.

    folder-recipe checklist ./archive
