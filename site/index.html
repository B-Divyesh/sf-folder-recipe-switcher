02 How it works

How recipe files work

A folder uses its own recipe file or the nearest one above it. Inspect shows the source before you open an editor.

  1. 01

    Save profiles

    Name each editor profile and record why it fits the shoot.

    folder-recipe init ./shoot …
  2. 02

    Check a folder

    See whether this folder or a parent saved the recipe file, beside file types.

    folder-recipe inspect ./shoot/selects
  3. 03

    Export a checklist

    Create editor and profile steps for every folder with a recipe file.

    folder-recipe checklist ./archive

06 Scope

What Folder Recipe does not do

It does not edit photos, apply profiles, or manage an editor catalogue. It records your choices in files you control.

Folder Recipe saves editor profiles beside photo folders.
